# Анализ сканирования сервера

Представлен отчет о результатах сканирования сервера (10.10.10.233) с использованием автоматического сканера портов и инструмента Gobuster.

## Основные выводы

1. **Открытые порты:**
   - Порт 22 — SSH
   - Порт 80 — веб-сервер (Apache)

2. **Доступ к веб-среде:**
   - Сервер использует CMS Drupal (версия 7)
   - В файле `robots.txt` обнаружено 36 запрещенных элементов
   - Элемент `/robots.txt` содержит 36 запрещенных записей

3. **Доступ к Wordpress-страницам:**
   - Используется файл `xmlrpc.php` — это уязвимая функция для WordPress-блогов
   - Также обнаружены директории: `/modules`, `/includes`, `/themes`, `/scripts`, `/misc`, `/profiles`, `/sites`, `/.htaccess`, `/.htpasswd`

4. **Отчет о сканировании:**
   - Gobuster не смог сканировать директории из-за блокировки
   - Инструмент Gobuster обнаружил несколько файлов, связанных с WordPress, но ничего особенно критичного не выявил

## Примечания

- Сервер использует PHP 5.4.6 и Drupal 7
- Некоторые директории (например, `/.htaccess`) недоступны из-за блокировки
- В `robots.txt` обнаружено 36 запрещенных элементов, включая `/robots.txt` самого файла
