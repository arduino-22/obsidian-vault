## Установка Obsidian

### На Windows

Перейдите на [страницу скачивания](https://obsidian.md/download)... и нажмите «Скачать».

### На Kali

Перейдите на [страницу скачивания](https://obsidian.md/download) и скачайте AppImage. Положите его в любую директорию, которую вы хотите (я использую `~/Applications`).

Вы можете двойным кликом на файл запустить его, или запустить с `/path/to/Obsidian-0.11.9.AppImage`.

При запуске может возникнуть следующая ошибка:

```bash
┌──(mac㉿kali)-\[~/Applications\]  
└─$ ./Obsidian-0.11.9.AppImage  
\[2122:0327/193255.690087:FATAL:setuid\_sandbox\_host.cc(158)\] The SUID sandbox helper binary was found, but is not configured correctly. Rather than run without sandboxing I'm aborting now. You need to make sure that /tmp/.mount\_Obsidi1nvAuD/chrome-sandbox is owned by root and has mode 4755.  
Trace/breakpoint trap
```

Чтобы исправить это, запустите obsidian с флагом `--no-sandbox`.

Я настроил этот alias в `~/.bashrc`:

```bash
alias obsidian="~/Applications/Obsidian-0.11.9.AppImage --no-sandbox"
```

Наконец, если Obsidian перестает отвечать при запуске, обновите Kali:

```bash
sudo apt update
sudo apt full-upgrade -y
```

## Скачивание хранилища

Вам нужно [скачать git](https://git-scm.com/downloads). Это быстрый и простой процесс.

На Windows, откройте меню «Start» и найдите «Git Bash», затем нажмите на него, чтобы открыть bash-терминал (или перейдите в директорию, в которую вы хотите установить записки, затем щелкните правой кнопкой и нажмите «Git Bash Here»). На Unix откройте любой терминал.

В этом Git Bash/терминале введите следующий команду:

```bash
git clone git@github.com:Twigonometry/Cybersecurity-Notes.git
```

Если вам некомфортно использовать командную строку, можно установить [GitHub Desktop](https://desktop.github.com/).

После клонирования репозитория откройте Obsidian и нажмите «Open folder as vault», затем выберите папку `Cybersecurity-Notes`, которую только что создал Git. Вы готовы!

## Использование Obsidian

Технически вы могли бы просмотреть эту информацию прямо из GitHub, поскольку все файлы — Markdown, но она создана для просмотра в Obsidian, где код выглядит красиво и ссылки между записками действительно работают.

Вы можете увидеть, как эта коллекция записок развивалась со временем, в истории git. Введите `git log`, чтобы увидеть список коммитов, и `git checkout [HASH]`, чтобы вернуться в прошлое и посмотреть состояние репозитория тогда.

### Полезные горячие клавиши

Obsidian поддерживает широкий спектр горячих клавиш. Некоторые из наиболее полезных перечислены ниже, если вы увлекаетесь использованием Zettelkasten (кто не увлекается?)

**(\*) указывает на пользовательскую горячую клавишу**

Глобальный поиск: `Ctrl + Shift + F`

(\*) Открыть случайную запись: `Ctrl + R`

Превратить строку в список/переключить статус: `Ctrl + Enter` (одно нажатие — в список, два нажатия — в список, три нажатия — переключить статус)

Режим переключения: `Ctrl + E`

(\*) Переключить режим по умолчанию: `Ctrl + Shift + E` (полезно, когда вы хотите войти в графиковый вид и перемещаться между записками, но оставаться в режиме просмотра — это поведение [не является по умолчанию](https://forum.obsidian.md/t/not-retaining-preview-mode-when-switching-to-graph-view-and-back/3080/2))

(\*) Открыть локальный график: `Ctrl + L` (полезно для исследования связанных записок — он откроет график в новой панели, и щелчок связанной записи откроет ее вместе с локальным графиком)

Вставить простой текст: `Ctrl + Shift + V` (избегает символы экранирования в выходных данных nmap/autorecon и т.д. — полезно, если вы хотите отфильтровать/редактировать этот репозиторий)

(\*) Разделить панель вертикально: `Ctrl + Alt + V`

(\*) Разделить панель вертикально: `Ctrl + Alt + H`

Назад/вперед: `Alt + Left-Arrow`/`Alt + Right-Arrow`
