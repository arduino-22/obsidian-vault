# Эскалация привилегий

## Директории и файлы с правом записи
```
find / -writable -type d 2>/dev/null
```

## Экземпляры программ с suid-правилами
```
find / -perm -u=s -type f 2>/dev/null
```

## Поиск экземпляров программ с возможностью эксплойта возможностей
```
/usr/sbin/getcap -r / 2>/dev/null
```

## Поиск паролей в процессах
```
watch -n 1 "ps -aux | grep pass"
```

## Поиск паролей в tcpdump
```
sudo tcpdump -i -lo -A | grep "pass"
```

## Поиск чувствительных файлов 
```
find / -name *txt, *config, *conf*, *docx* 
```
