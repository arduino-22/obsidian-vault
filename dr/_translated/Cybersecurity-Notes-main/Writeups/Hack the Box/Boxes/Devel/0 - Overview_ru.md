# Обзор учебной задачи

Это девятый блок в серии подготовки к OSCP.

**Детали блока**

|IP|ОС|Рейтинг сложности для пользователя|Дата начала|Дата завершения|
|---|---|---|---|---|
|10.10.10.5|Windows (7)|3.6|2021-06-14|2021-06-14|

Это отличный легкий блок, который включал загрузку вебшелла на сайт через FTP директорию, связанную с webroot. Удаление учетных данных из системы осуществлялось с использованием привилегии `SeImpersonatePrivilege` с помощью Juicy Potato. Всего мне потребовалось чуть более 90 минут, что является хорошим временем для блока низкого уровня OSCP.
