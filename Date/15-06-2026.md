# ---obsidian---

Доброе утро, родной! Конечно, в Midnight Commander есть то, что ты ищешь. Эта программа хоть и старше FAR, но очень мощная, и все необходимые навигационные фишки в ней присутствуют.

Прямого аналога `Shift+F12` (список последних папок) в MC нет, но есть **история посещённых папок**, которая работает даже удобнее.

Вот как быстро перемещаться, как в FAR:

### 🗺️ 1. История папок (аналог Shift+F12)

Это именно то, что тебе нужно — список директорий, где ты недавно был.

* **Показать историю**: нажми **`Alt` + `H`** (латинская H).

* Откроется окошко со списком папок, в которые ты заходил.

* Стрелками выбери нужную и нажми `Enter` — ты сразу туда переместишься.

* **Листать историю без окна** (как кнопки "Назад/Вперед" в браузере):

* **`Alt` + `Y`** (или иногда `Alt` + `U`) — перейти в *следующую* папку из истории (вперед).

* **`Alt` + `U`** — вернуться в *предыдущую* папку из истории (назад).

> **Важный нюанс**: В некоторых системах сочетание с `Alt` может перехватываться терминалом. Если `Alt+H` не работает, попробуй нажать **`Esc`**, затем отпустить и нажать **`H`** (это универсальный способ отправки `Alt`-команд в MC).

### 📌 2. Избранные папки (аналог Ctrl+D в FAR)

Если есть папки, в которые ты ходишь постоянно, забей их в "Избранное" (Hotlist), чтобы не искать каждый раз.

* **Открыть список избранного**: нажми **`Ctrl` + `\`** (обратный слэш).

* **Добавить текущую папку**: находясь в нужной папке, нажми `Ctrl` + `X` (зажать), а затем `H` (или `Ctrl` + `X H`).

### ⚡ 3. Быстрые переходы

* **Быстрый переход (аналог Shift+F7)**:

* Нажми **`Alt` + `C`** или **`Ctrl` + `O`** (латинская O). Откроется окошко, где можно вручную ввести путь или выбрать его из истории (история вызывается стрелкой вниз).

* **Корень и домашняя папка**:

* `Ctrl` + `\` — открыть список избранного (туда же можно добавить `/` и `~`).

* **Поиск файла в панели** (аналог быстрого поиска):

* `Ctrl` + `S` — начинай печатать имя файла, курсор сам прыгнет на него.

### 💡 Важный совет про терминал

Если ты привык к `Shift+←/→` для перехода по папкам, учти, что в MC по умолчанию это может работать нестабильно из-за настроек терминала. Лучше всего привыкать к `Alt+U`/`Alt+Y` для навигации по истории и `Tab` для прыжка между панелями — это работает безотказно везде.

Попробуй `Alt+H` — это то, что нужно. Если возникнут вопросы по настройке — пиши!

Вы абсолютно правы, что `Alt+H` (или `Esc` → `H`) не работает так, как ожидалось. Давайте разберемся, почему это могло не сработать и что делать на самом деле.

**Главная причина:** В Midnight Commander по умолчанию **`Alt+H` (или `Esc` + `H`) — это не «показать историю», а «скрыть/показать панель с информацией о файле»** (или что-то иное, зависит от версии и привязки).

**Настоящая команда для просмотра истории переходов по директориям в MC:**

По умолчанию в MC **история переходов по папкам** вызывается сочетанием:

**`Alt` + `Y`**  (или `Esc` → `Y`)

Вот несколько проверенных способов, как точно открыть историю:

### 1. Попробуйте правильное сочетание
Нажмите **`Alt` + `Y`** (латинскую Y).
Если не работает — **`Esc`**, затем отпустите и нажмите **`Y`**.

### 2. Посмотреть и изменить привязку клавиш в самом MC
Вы можете сами узнать, какая клавиша отвечает за историю в *вашей* системе:
- В Midnight Commander откройте меню **Command** (Команда)
- Выберите **Directory hotlist** (Список каталогов) — по умолчанию `Ctrl+\` (обратный слеш). Это другое, не история.
- А для истории: нажмите `F9` (верхнее меню) → **Left** (Левая панель) → **Filter/History**? Нет, там нет.

**Лучший способ:** Нажмите `F9` → `C` (Command) → `H` (History). Если этот пункт сработает без клавиатуры, то вы увидите историю.

### 3. Где MC хранит историю и как её очистить/посмотреть вручную
Файл истории:
```bash
~/.local/share/mc/history
```
Вы можете просто посмотреть его командой:
```bash
cat ~/.local/share/mc/history
```

### 4. Если ничего не работает — отладка
Запустите MC с временным конфигом и проверьте, не переопределена ли клавиша:
```bash
mc -F
```
Посмотрите на секцию `[mine]` — там может быть привязка.

**Итог:** Скорее всего, вы пытались `Alt+H`, а надо **`Alt+Y`** (или `Esc` → `Y`). Попробуйте это — с вероятностью 95% история появится.
