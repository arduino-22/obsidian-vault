# Идентификация хэшей
Выполните этот запрос, чтобы получить список потенциальных алгоритмов хэширования

```bash
$ hashid [HASH]
```

## Сочетание с Hashcat

Выполните эти команды через [[Hashcat]], чтобы узнать, для каких целей они используются для взлома:

```bash
$ hashcat --example-hashes | grep [ALGORITHM-NAME] -B 2
```

Если у вас много кандидатов, проверьте их все с помощью одной команды:

```bash
$ hashid [HASH] | awk '{print $2}' | while read line; do hashcat --example-hashes | grep $line -B 1; done
```

Это быстрый и простой скрипт bash, который берет вторую колонку результата `hashid` (угаданный алгоритм) и передает его в Hashcat. Он может быть улучшен, так как также передает сам хэш в команду `grep`.
