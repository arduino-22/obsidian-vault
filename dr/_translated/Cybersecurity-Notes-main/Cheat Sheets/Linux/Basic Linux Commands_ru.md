
# Основные команды Linux

*Примечание*: В этих и всех других примерах в справочниках `$` перед командой указывает на ввод в командной строке Linux. Это не часть самой команды — он показывает, какие строки являются вводом, а какие — выводом (строки без `$`).

## Проверка текущего рабочей директории

Где вы находитесь в этом файловом системе? Узнайте с помощью `pwd`:

```bash
$ pwd
/var/www/html
```

Полезно после запуска с shell или если вы заблудили.

## Изменение директории

Команда `cd` изменяет директорию:

```bash
$ pwd
/home/mac
$ cd /opt
$ pwd
/opt
```

Перейдите в вашу домашнюю директорию:

```bash
$ cd ~
```

Вернитесь в предыдущую директорию:

```bash
$ cd -
```

Перейдите в корень файлового система:

```bash
$ cd /
```

## Показать файлы

Показать файлы в текущей рабочей директории:

```bash
$ ls
```

Показать все файлы, включая скрытые (перед которыми стоит `.`, например `.env`):

```bash
$ ls -a
```

Отобразить дополнительную информацию о файлах, включая временные метки и владение файлом:

```bash
$ ls -l
```

Сочетать оба параметра:

```bash
$ ls -la
```

## Смена пользователя

Команда `su` меняет на другого пользователя на устройстве. Вы должны знать его пароль.

Эта команда попытается сменить на пользователя `jane`:

```bash
$ su jane
```

Если не указан именованный пользователь, `su` попытается войти как root:

```bash
$ su
```

Использование флага `-` имитирует реальный вход — часто видите `su -` в записях как сокращение от `su root`:

```bash
$ su -
```

Однако эта команда фактически такая же, как и вышеупомянутая, за исключением нескольких [незначительных различий](https://unix.stackexchange.com/questions/15611/what-is-the-difference-between-su-and-su-root), например очистки переменных окружения.

## grep

`grep` — очень полезная команда, которая позволяет искать содержимое файлов и выводы команд терминала.

**Искать в файле**

```bash
$ grep [SEARCH_TERM] /path/to/file
```

или с использованием пруфа (`|`):

```bash
$ cat /path/to/file | grep [SEARCH_TERM]
```

**Искать в выводе терминала**

Можно использовать оператор пруфа, чтобы запустить `grep` на выводе любой команды. Обычный случай — поиск в выводе директории:

```bash
$ ls -la | grep [SEARCH_TERM]
```

## awk
`awk` может использоваться для обработки структурированных текстов и извлечения конкретных полей. Можно считать как способ выбора конкретной колонки из большого объема структурированных данных.

Например, список имён сотрудников:

```bash
$ cat employees
John Doe
Jane Doe
```

`awk` может быть использован для извлечения имен первых сотрудников:

```bash
$ cat employees | awk '{print $1}'
```

Здесь `$x` представляет собой `x-ю` колонку (с индексацией 1).

Можно указать другой «разделитель поля» с флагом `-F`:

```bash
$ cat employees
John:Doe
Jane:Doe
$ cat employees | awk -F ':' '{print $1}'
John
Jane
```
