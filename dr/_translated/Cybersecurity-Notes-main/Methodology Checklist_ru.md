# Методологический чеклист

Большинство аудитов включают следующие элементы:
- перечисление
	- выявление работающих сервисов и цели целевой системы
	- повторное перечисление сервисов
	- поиск версий программ
	- загрузка файлов

- автоматизированное веб-перечисление
	- проверка, что движок сайта работает
	- использование Burp Suite для анализа трафика
	- проверка источника сайта

- ручное веб-перечисление
	- проверка HTTP и HTTPS версий
	- проверка IP-адресов и доменов
	- включение Burp Suite для анализа трафика
	- просмотр источника сайта
	- поиск комментариев, ссылок на файлы и скрытых элементов
	- проверка robots.txt
	- поиск пользовательских имен в сайте

- SMB-перечисление
	- использование smbmap для сканирования серверов
	- использование smbclient для подключения к серверам
	- использование impacket для подключения к SMB-серверам
