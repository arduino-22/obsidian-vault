# Ключевые уроки, извлеченные

- FTP можно загружать в бинарном режиме (`ftp> binary`), что полезно при передаче файлов `.exe`
- Использование Juicy Potato для доступа к SYSTEM, с помощью обратного шелла PowerShell
- Внимательно прочитайте `systeminfo` — может показаться `x64` процессор, но система на самом деле может быть 32-битной
