
# smbclient

`smbclient` — это инструмент для подключения к серверам Samba, которые используют протокол файлообмена на основе Windows.

## Основная синтаксис

Подключение к серверу:

```bash
$ smbclient //[IP]
```

Подключение к конкретному пуле:

```bash
$ smbclient //[IP]/[SHARE]
```

### Основные команды

**Загрузка и скачивание файлов**

Используйте `get`, чтобы скачать файл в текущую рабочую директорию локального компьютера:

```bash
smb: \> get [FILE]
```

Используйте `put`, чтобы загрузить файл из текущей рабочей директории локального компьютера:

```bash
smb: \> put [FILE]
```

**Навигация в Samba**

Используйте `dir`, чтобы просмотреть файлы:

```bash
smb: \> dir
```

Используйте `cd`, чтобы изменить директорию:

```bash
smb: \> cd [DIRECTORY_PATH]
```

Используйте `lcd`, чтобы изменить директорию локально:

```bash
smb: \> lcd [LOCAL_DIRECTORY_PATH]
```

Используйте `exit`, чтобы выйти из клиента:

```bash
smb: \> exit
```

## Скачивание файла

Скачивание файла из Samba пула в одной строке:

```bash
$ smbclient '//[IP]/[SHARE]' -c 'lcd [DOWNLOAD_PATH]; cd [DIRECTORY]; get [FILENAME]'
```

Флаг `-c` выполняет последовательность команд. `lcd` изменяет директорию на локальном компьютере (то есть в вашем Linux-хосте), поэтому используйте его для указания места, куда будет сохранён скачанный файл.

## Загрузка файла

Загрузка файла в Samba пуле в одной строке:

```bash
$ smbclient '//[IP]/[SHARE]' -c 'cd [REMOTE_PATH]; lcd [LOCAL_DIRECTORY]; put [LOCAL_FILENAME]'
```

Или с помощью `curl`:

```bash
$ curl --upload-file /path/to/file -u [USERNAME] smb://[IP]/[SHARE]
```

## Просмотр пулов

Используйте флаг `-L` для просмотра пулов:

```bash
$ smbclient -L hostname -U username
```

## Монтирование пула

Можно использовать инструмент `mount` для монтирования Samba пула.

Сначала создайте директорию `/mnt`, если её нет. Для этого требуются права root:

```bash
$ sudo mkdir /mnt
```

Затем создать поддиректорию в этой директории и назвать её по имени пула, который вы хотите монтировать:

```bash
$ sudo mkdir /mnt/[SHARE]
```

Затем установите `cifs-utils`, если они ещё не установлены:

```bash
$ sudo apt install cifs-utils
```

Эти утилиты помогут вам монтировать SMB пула удалённо.

Затем выполните команду для монтирования пула:

```bash
$ sudo mount -t cifs //[IP]/[SHARE] /mnt/[SHARE]
```

Нажмите Enter при запросе пароля.

### Размонтирование пула

Размонтируйте пул, если вам больше не нужен:

```bash
$ sudo umount /mnt/[SHARE]
```
