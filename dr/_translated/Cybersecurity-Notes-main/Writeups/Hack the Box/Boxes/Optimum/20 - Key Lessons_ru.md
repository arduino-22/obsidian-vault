# Ключевые уроки
Вот некоторые ключевые вещи, которые я узнал из этой папки:
- Попробуйте все инструменты! Могут существовать множество эксплойтов — сначала выбирайте самый новый, и не сдавайтесь, если один из них не работает
- Вы можете использовать `wget` в качестве альтернативного метода скачивания, когда PowerShell вызывает проблемы
- Учитывайте *тип* шелла, в котором вы находитесь — это может быть PowerShell, а не командный пункт, что изменит синтаксис выполняемых команд
