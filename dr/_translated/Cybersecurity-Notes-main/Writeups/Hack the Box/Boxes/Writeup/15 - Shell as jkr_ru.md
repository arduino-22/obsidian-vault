### Подробное описание

#### 1. Приступ к системе и флаг

После успешного запуска `run-parts` мы можем просматривать выполняемые процессы (`pspy`). Мы видим, что `chmod +x` не сохраняется после выполнения скрипта, поэтому нужно было быстро войти в систему.

Затем мы обнаруживаем файл `/tmp/twig` с UUID: `eeba47f60b48ef92b734f9b6198d7226`. Это и есть флаг.

#### 2. Создание root-ключа (`twig`)

Поскольку в системе нет файла `/root/.ssh/id_rsa`, мы создаем новый файл `twig` с `#!/bin/sh` в начале. Это позволяет нам запустить скрипт как root.

```bash
twig-4.4# echo '#!/bin/sh' > /tmp/twig
twig-4.4# echo 'cp /bin/bash /tmp/twig && chmod u+s /tmp/twig' >> /usr/local/sbin/run-parts
```

Теперь `twig` — это SUID-скрипт, поэтому запускается как root.

#### 3. Подключение к SSH

`twig` подключается к серверу `jkr@10.10.10.138`.

```bash
twig-4.4# ssh jkr@10.10.10.138
jkr@10.10.10.138's password: 
```

#### 4. Получение root-пароля

После ввода пароля `jkr` получает доступ к системе.

```bash
jkr@10.10.10.138# 
```

#### 5. Скопирование флага

Теперь мы скопируем флаг из `/tmp/twig` в файл, который будет использоваться для запуска `run-parts`.

```bash
jkr@10.10.10.138# cp /tmp/twig /tmp/twig
```

#### 6. Запуск `run-parts` и получение shell

Скрипт `run-parts` выполняет несколько команд:

1.  **Создание файла `/tmp/`:** Создается папка, где будет храниться флаг.
2.  **Копирование `bash`:** Создается файл `twig-4.4$`.
3.  **Придание SUID-прав для `twig`:** `chmod u+s` делает файл скрипта root-кодированным, что позволяет запускать его как root.
4.  **Запуск `run-parts`:** Скрипт выполняет команду `cp /bin/bash /tmp/twig && chmod +x /tmp/twig`, чтобы создать файл `bash` и сделать его SUID.
5.  **Подключение к SSH:** `twig` подключается к `jkr@10.10.10.138`.
6.  **Получение root-права:** После ввода пароля `jkr` получает доступ к системе.
7.  **Запуск `run-parts`:** Скрипт выполняет команду `/bin/sh /usr/local/sbin/run-parts --lsbsysinit /etc/update-motd.d`, которая записывает список файлов MOTD в `/tmp/twig`.
8.  **Подключение к SSH:** `twig` подключается к `jkr@10.10.10.138`.
9.  **Получение root-пароля:** После ввода пароля `jkr` получает доступ к системе.
10. **Запуск `run-parts`:** Скрипт выполняет команду `/bin/sh /usr/local/sbin/run-parts`, которая записывает флаг `eeba47f60b48ef92b734f9b6198d7226` в `/tmp/twig`.
11. **Получение shell:** После этого `twig` запускает `bash`, что дает нам root-сhell.
