
# nmap
Инструмент для выявления служб, работающих на каждом порте у определённого хоста

Репозиторий можно найти по адресу [https://github.com/nmap/nmap](https://github.com/nmap/nmap)

## Установка

На официальной странице nmap имеются [подробные инструкции по установке](https://nmap.org/book/install.html), если вы не можете найти нужную информацию. Я описал наиболее распространённые сценарии использования.

### Kali Linux

`nmap` предустановлен на Kali Linux

### Другие Linux-дистрибуции

`nmap` имеет пакет `apt`, и его можно установить с помощью:

```bash
$ sudo apt install nmap
```

Чтобы проверить, что ваша дистрибуция имеет этот пакет, выполните `apt search nmap`

### Из исходного кода

Вы можете установить `nmap` из исходного кода, следуя инструкциям репозитория [installing](https://github.com/nmap/nmap#installing)

## Базовая синтаксис

**Сканирование цели**

Для цели с IP-адресом `a.b.c.d` выполните следующую команду:

```bash
$ nmap a.b.c.d
```

По умолчанию `nmap` сканирует 1000 самых распространённых портов

**Команда nmap для общих целей**

Я выполняю эту команду при первичном поиске большинства целей. Она показывает порты при их обнаружении с флагом `-v`, пытается определить версии служб и запускает некоторые стандартные скрипты, а затем выводит результаты в директорию `nmap/`, которую необходимо создать первым (`mkdir nmap`):

```bash
$ nmap -v -sC -sV -oA nmap/ a.b.c.d
```

**Решение проблем**

Если ваши запросы отклонены, попробуйте выполнить `nmap` с флагом `-Pn`:

```bash
$ nmap -Pn a.b.c.d
```

Посмотрите, что делает `nmap` поставив его в verbose режим с флагом `-v`. Это позволит вам видеть порты при их обнаружении и решать проблемы.

```bash
$ nmap -v a.b.c.d
```

## Дополнительная информация

`nmap` способен запускать несколько скриптов для получения дополнительной информации о службе. Указать флаг `-sC`, чтобы запустить стандартные скрипты:

```bash
$ nmap -sC a.b.c.d
```

`nmap` также может определить версии программ, работающих на порту. Используйте флаг `-sV` для этого:

```bash
$ nmap -sV a.b.c.d
```

`nmap` также может определить операционную систему с помощью флага `-O`:

```bash
$ nmap -O a.b.c.d
```

## Указание портов

**Сканирование одного порта**

Чтобы сканировать порт X, выполните следующую команду:

```bash
$ nmap -p X a.b.c.d
```

**Сканирование диапазона портов**

Чтобы сканировать порты X до Y (числово), выполните следующую команду:

```bash
$ nmap -p X-Y a.b.c.d
```

**Сканирование всех портов**

Чтобы сканировать все 65535 портов, выполните следующую команду:

```bash
$ nmap -p- a.b.c.d
```

Хорошей практикой является выполнение этой команды в фоновом режиме после первоначального сканирования 1000 портов `nmap`. Можно сделать это с помощью `sleep`, ожидая 5 минут, так:

```bash
$ sleep 300; nmap -v -p- -oA nmap/target-all-ports a.b.c.d
```

Это сохранит вывод в ту же директорию, что и в **Команде nmap для общих целей** выше, но с другим суффиксом.

Не необходимо запускать скрипты при этом сканировании — они полезны только для обнаружения открытых портов, которые вы могли пропустить, и после этого можно повторно определить их с помощью скриптов.

## Сканирование UDP

Некоторые службы работают только через UDP и могут быть пропущены стандартным TCP-сканированием. Сканируйте UDP с флагом `-sU`:

```bash
$ nmap -sU a.b.c.d
```

Практический пример: [Ippsec's Intense Video](https://youtu.be/nBg6zUalb7c?t=143)

## Настройка скорости

Используйте флаг `--min-rate`, чтобы увеличить скорость сканирования. Это изменяет минимальное количество пакетов, отправляемых в секунду. Полезно, если вы хотите быстро повторно сканировать, например, полный порт-скан или UDP-скан.

```bash
$ nmap --min-rate 10000 a.b.c.d
```

Сделайте это только если вам не важно вызвать сбой на цели или если вас волнует операционная безопасность — высокий минимальный уровень скорости будет заметен в логах сервера и системах обнаружения вторжений (IDS).

В противном случае можно также установить флаг `--max-rate`, чтобы установить верхнюю ограничение количества запросов в секунду. Полезно, если вы хотите избежать обнаружения.

```bash
$ nmap --max-rate 30 a.b.c.d
```

### Шаблоны времени

`nmap` предоставляет несколько предустановленных шаблонов времени, которые выбираются с флагом `-T`. Они устанавливают множество параметров, связанных со скоростью, включая те, что вы указали.

```bash
$ nmap -T paranoid|sneaky|polite|normal|aggressive|insane a.b.c.d
```

Можно также использовать числовые эквиваленты, от `-T0` до `-T5`. [Документация nmap](https://nmap.org/book/man-performance.html) рекомендует `-T4` при высокой широкополосной скорости и `-T1` или ниже для избегания обнаружения IDS.

Можно также комбинировать шаблон с конкретным флагом производительности, например `--scan-delay` между запросами, чтобы избежать некоторых лимитов скорости:

```bash
$ nmap -T4 --scan-delay 1s a.b.c.d
```

Это сохранит все остальные настройки режима `aggresive`, такие как уменьшенное `max-retries`.

Полные детали значений шаблонов времени доступны по адресу [https://nmap.org/book/performance-timing-templates.html](https://nmap.org/book/performance-timing-templates.html)
