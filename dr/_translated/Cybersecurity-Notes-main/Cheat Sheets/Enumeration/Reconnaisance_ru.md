
# Расшифровка
Эти инструменты помогают понять, что делает цель и какие сервисы работают на ней.

## nmap

Я всегда начинаю сканирование с `nmap`. Это инструмент для обнаружения открытых портов (точек связи) в сети и сервисов, работающих на них.

Хороший общий пример команды `nmap` выглядит так:

```bash
$ nmap -v -sC -sV -oA nmap/ [IP/HOSTNAME]
```

С помощью флага `-v` он отображает порты, находя их, пытается определить версии сервисов и запускает несколько по умолчанию, а затем выводит результаты в директорию `nmap/`, которую необходимо создать первым (с помощью `mkdir nmap`).

По умолчанию `nmap` сканирует только 1000 наиболее распространенных портов. Чтобы сканировать все порты, выполните эту команду:

```bash
$ nmap -p- -oA nmap/all-ports [IP/HOSTNAME]
```

Лучше сделать это после завершения первого сканирования.

Более подробно о различных функциях `nmap` можно прочитать в [[nmap|nmap cheatsheet]], включая:
- Инструкции по установке
- Сканирование конкретных портов
- Сканирование UDP сервисов
- Тайминг и избегание обнаружения

## Autorecon

Этот инструмент выполняет ряд автоматизированных сканирований. Он начинается с сканирования `nmap`, а результаты этого используются для запуска других сканирований, например, обнаружение директорий с помощью [[Gobuster]].

Скачайте инструмент из [Git Repository](https://github.com/Tib3rius/AutoRecon), где также можно найти множество дополнительных деталей использования.

По личному предпочтению я предпочитаю вручную выполнять стандартное расшифровывание и запускать `autorecon` в фоновом режиме. Это помогает мне лучше обрабатывать информацию, которую получаю.

Это полезно, потому что он не может забыть важные шаги, например, сканирование всех портов с помощью `nmap`.

**Базовая синтаксис**

```bash
autorecon [IP/Domain Name]
```

**Множество целей**

Указывайте несколько целей после определения опций (флагов). Например:

```bash
autorecon [OPTIONS] a.b.c.d foo.bar w.x.y.z
```

Или используйте CIDR-обозначение для определения диапазона целей:

```bash
autorecon [OPTIONS] a.b.c.d/24
```

Или используйте файл цели с флагом `-t`:

```bash
autorecon -t /path/to/target_file a.b.c.d
```

**Опции вывода**

Установите директорию вывода с флагом `-o`:

```bash
autorecon -o /path/to/output_dir example.com
```

### Запуск веб-сервера

После завершения сканирований вы можете легко просмотреть результаты, запустив веб-сервер в директории `/results` и посетив его по адресу localhost:

```bash
┌──(mac㉿kali)-[~/Documents/HTB/BOX/results/]
└─$ python3 -m http.server
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

Затем посетите `http://localhost:8000` и просмотрите результаты в браузере.
