
# Ключевые уроки

Вот некоторые ключевые вещи, которые я выучил на этой машине:
- Основная инвентаризация серверов SMB с помощью `smbmap`
- Нулевая аутентификация и аутентификация с определёнными имёнными учётными записями гостей
- Использование флага `--script vuln` в nmap для сканирования уязвимостей
- Важные навыки выполнения скриптов Python разных версий и установка пакетов для конкретных версий Python
- Инвентаризация имённых pipe с помощью модуля `auxiliary/scanner/smb/pipe_auditor` в Metasploit
- Генерация shellcode для Windows-платформ с помощью `msfvenom`
- Настройка эксплойта Eternal Blue для соответствия имённым pipe и учётных записям SMB целевой машины
